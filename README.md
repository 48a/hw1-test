# Преподавательская Оценка Студентов

Консольный учёт студентов, критериев и оценок одного курса. Есть итог по весам,
сводка по группе и экспорт CSV. Данные живут до выхода из программы.

## Запуск

```sh
make run
make demo
make check
make cover
```

Команды и примеры: [спецификация](docs/spec.md), [демонстрация](docs/demo.txt).
Имена могут содержать пробелы: `student s1 Анна Иванова`.

## Модель DDD

Cтудент (`Student`), критерий (`Criterion`), оценка (`Evaluation`), итог (`Total`).

| Понятие | Решение |
|---|---|
| Entity | Студент и критерий имеют ID; одинаковое имя не делает студентов одной сущностью. |
| Value Object | Оценка - значение «студент, критерий, балл». При исправлении заменяется целиком. |
| Агрегат | `Course` содержит студентов, рубрикатор и оценки. Менять их можно только его методами. |
| Инварианты | ID уникальны; максимум и вес положительны; балл конечен и в диапазоне |
| Repository | Порт `app.Repository`; адаптер `memory.Repository` хранит копии курса. |
| Domain Service | `domain.Calculator` считает итог по рубрикатору и текущим оценкам. |

Итог: `100 * sum(балл / максимум * вес) / sum(вес)`.
Например, 8/10 с весом 3 и 20/20 с весом 1 дают **85%**.
`total s1` считает пропуски нулём; `total s1 final` требует всех оценок.
Пропуск отличается от выставленного нуля. Итог не сохраняется; округление - только в выводе.
`summary` показывает текущие итоги, среднее, минимум и максимум по всей группе.

## Архитектура

Ports & Adapters. Зависимости направлены к модели:

```text
cmd/pos                  DI-контейнер и запуск
internal/cli ──────┐
internal/csvexport ┴─→ internal/app ─→ internal/domain
internal/memory ───────────────────→ internal/domain
```

## Паттерны

| Группа | Паттерн и назначение |
|---|---|
| Порождающий | Factory: `Course.Evaluate` - единая фабрика оценок, проверяет связи и диапазон до создания. |
| Структурный | Facade: `app.Service` объединяет загрузку, доменные операции, сохранение и экспорт; CLI только разбирает и выводит. |
| Поведенческий | Strategy: `MissingAsZero` и `RequireAll` меняют правило учёта пропусков в `Calculator`. |
