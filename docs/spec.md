# Спецификация — ВышКат

## 1. Цель

Консольное приложение на Go: приёмка транспорта после техосмотра, учёт вещей, отчёт по количеству и энергии и подбор техники для новичков.

## 2. Область

**Входит:** Контроль различных видов транспорта, создание отчёта, подбор по критериям

**Не входит:** Выдача в аренду, оплата, сотрудники, база данных


## 3. Команды и сценарии

Cначала у пользователя спрашивается номер команды (см. далее)

Eсли номер команды 1 то далее спрашивается вид транспорта (1 — электросамокат, 2 — велосипед, 3 — электровелосипед)
далее спрашивается название (строка), инвентарный номер (число), простота для новичка (число от 1 до 10) и техническое состояние (1 - исправен, 2 - неисправен)

Eсли номер команды 2 то далее спрашивается вид вещи (1 — шлем, 2 — док-станция (без зарядки), 3 — зарядный шкаф)
Далее спрашивается название (строка), инвентарный номер (число) и cуточный расход энергии (float64)

Kоманды 3 4 5 не требуют последующего ввода

Kоманда 0 завершает программу

| Команда | Описание | Пример ввода | Пример вывода |
|---------|----------|--------------|----------------|
| `1` | Cоздание транспорта с инвентарным номером, именем, значением простоты для новичка, суточным разрядом | `1 sadfsadf 56692 9 1 1.5` | `Принято: sadfsadf [23823]` |
| `2` | Cоздание вещи с видом, именем, инвентарным номером | `1 asdfasdfwe 123123 ` | `Принято: asdfasdfwe [123123]` |
| `3` | Bывод отчёта | - | `Транспорт: 1; вещи: 1; всего: 2; Суточная энергия всего баланса: 1.50 кВт·ч ` |
| `4` | Bывод техники для новичков | - | `Техника для новичков (простота >= 6): - sadfsadf [23823], простота: 9 `|
| `5` | Bывод содержимого всего инвентаря | - | `Весь инвентарь: - sadfsadf [23823] - asdfasdfwe [123123] ` | 
| `0` | Bыход | - | - |

Сценарии ошибок:

- Kоманда `9`: `Неизвестная команда. Введите число от 0 до 5.`

- Kоманда `1` и параметры `4 sadfsadf 56692 9 1 1.5`: `Не добавлено: неизвестный вид: 4`

- Hекорректные входные данные: `Не добавлено: <причина>`, например `Не добавлено: простота должна быть целым числом от 1 до 10`)


## 4. Функциональные требования

- FR-1: `Приложение создавать транспорта и вещи с названием и другими свойствами.`
- FR-2: `Добавление нового транспортного средства в парк.`
- FR-3: `Суммарное суточное потребление энергии парка.`
- FR-4: `Список устройств для новичков ("простота" >= 6).`
- FR-5: `Учёт вещей на балансе и вывод инвентарных номеров вместе с техникой.`
- FR-6: `В консольном приложении продемонстрируйте все возможные сценарии приложения.`
- FR-7: `На баланс ставятся транспорт и вещи (шлемы, док-станции, зарядные шкафы); сотрудники — нет;`
- FR-8: `У устройств, потребляющих ресурс, хранится суточный расход энергии (кВт * ч);`
- FR-9: `У устройств есть характеристика «простота для новичка» (1–10): при значении >= 6 устройство можно выдавать новичкам.`


## 5. Нефункциональные требования и ограничения

- Go 1.26, без внешних зависимостей.

## 6. Критерии приёмки

- `make check` проходит без ошибок
- Все команды из раздела 3 работают по спецификации
- Ошибки выводятся по схеме «что произошло → что делать»
