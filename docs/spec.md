# Спецификация "ПОС"

## 1. Цель

Преподаватель ведёт студентов одного курса, выставляет оценки и выгружает итоги.

## 2. Область

Входит: студенты, рубрикатор, исправление и отмена оценок, итог, сводка, CSV.

## 3. Команды и сценарии

Команды разделяются пробелами. Имя и название занимают остаток строки.
ID - латинские буквы, цифры, `_` и `-`. Дроби вводятся через точку.

---
| Команда | Действие / пример ответа |
|---|---|
| `student s1 Анна Иванова` | Добавить студента -> `Студент добавлен` |
| `students` | Список по ID -> `s1: Анна Иванова` |
| `criteria` | Список по ID -> `exam: Экзамен; максимум 10; вес 3` |
| `grade s1 exam 8` | Выставить или исправить оценку -> `Оценка сохранена` |
| `grades s1` | Все критерии с оценками или `нет оценки` |
| `ungrade s1 exam` | Отменить оценку -> `Оценка отменена` |
| `total s1` | Текущий итог, пропуски равны нулю |
| `total s1 final` | Окончательный итог: нужны все оценки |
| `summary` | Текущие итоги, среднее, минимум и максимум по группе |
| `export result.csv` | Выгрузить текущие итоги всех студентов в CSV |
| `help`, `exit` | Справка, выход (также EOF) |

Пример:

```text
student s1 Анна Иванова
student s2 Борис Петров
criterion exam 10 3 Экзамен
criterion lab 20 1 Практика
grade s1 exam 8
grade s1 lab 20
total s1 final
s1: 85.00%; оценено 2/2
summary
s1: Анна Иванова; 85.00%; оценено 2/2
s2: Борис Петров; 0.00%; оценено 0/2
Среднее: 42.50%; минимум: 0.00%; максимум: 85.00%
export result.csv
Экспорт завершён
exit
```

Ошибки: `grade s1 exam 12` отклоняется; неизвестный студент или критерий
отклоняется; повторный ID не заменяет запись. После ошибки REPL работает дальше.
Сообщение содержит причину и подсказку. Неудачная команда не меняет данные.

## 4. Правила

- Имена непустые; ID уникален внутри списка студентов или критериев.
- Максимум и вес - конечные положительные числа; балл конечен и лежит в `[0, максимум]`.
- Оценка относится только к студенту курса и критерию его рубрикатора.
- Итог: `100 × sum(балл / максимум × вес) / sum(вес)` по всем критериям.
  Веса нормируются; сумма не обязана быть 1 или 100. Пропуск отличается от оценки 0.
- Пустой рубрикатор не даёт итог. Режим `final` отклоняет неполный набор оценок.
- Итог вычисляется заново после исправления, отмены оценки или добавления критерия.
- Округление до двух знаков - только при выводе. Сводка включает всех студентов.
- Без студентов сводка пуста- CSV содержит только заголовок.
- CSV: `student_id,name,total_percent,graded,criteria`; строки по ID, UTF-8.
  Существующий файл не перезаписывается. Экспорт не служит сохранением курса.

## 5. Ограничения

Go 1.26, зависимости не добавляются. Один процесс, один пользователь, данные в памяти.
Domain не знает о консоли и файлах. DI собирается вручную в `cmd/pos`.
Три паттерна: фабрика оценок, фасад сценариев, стратегия учёта пропусков.

## 6. Критерии приёмки

- `make check` проходит.
- `make demo` выполняет сквозной пример и показывает CSV.
- Тесты проверяют инварианты, взвешенный итог, исправление и отмену, ошибки портов и REPL.
- README описывает DDD, слои, DI и назначение паттернов; решения записаны в ADR.
