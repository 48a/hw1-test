# 0001. Текстовое меню без TUI-библиотек

Дата: 2026-10-15

## Статус

Принято

## Контекст

ДЗ №1 — консольное приложение для управления зоопарком. Хочется дружелюбного
интерактива, но: (1) задание запрещает внешние зависимости; (2) важнее
архитектура и тестируемость, чем «красивости»; (3) CI должен оставаться простым.

## Решение

Меню — REPL-цикл на `bufio.Scanner` в пакете `internal/cli`: читаем строку,
разбираем на команду и аргументы, выполняем. Ввод-вывод параметризован
(`io.Reader`/`io.Writer`), чтобы тестировать без реальной консоли.

## Альтернативы

- `bufio.Reader.ReadString` — чуть гибче, но многословнее; Scanner покрывает все команды.
- TUI-фреймворк (bubbletea, tview) — внешняя зависимость и заметный порог входа; отклонено требованиями задания.
- Флаги командной строки (`flag`) без цикла — не соответствует формату «управление зоопарком» из задания.

## Последствия

- Плюсы: ноль зависимостей; REPL легко тестировать через `strings.Reader`; код помещается в один файл.
- Минусы: нет автодополнения и стрелочной навигации; команды нужно помнить (смягчается командой `help`).
