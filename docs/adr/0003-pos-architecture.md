# 0003. Слои ПОС

Дата: 2026-11-23

## Статус

Принято.

## Контекст

Нужны DDD, порты, консоль и DI без новых зависимостей.

## Решение

Ports & Adapters: `internal/domain` - модель; `internal/app` - сценарии и порты;
`internal/cli`, `internal/memory`, `internal/csvexport` - адаптеры.
Зависимости: адаптеры -> app -> domain. Domain использует только стандартную библиотеку.
`cmd/pos` содержит типизированный DI-контейнер и запуск. Модуль в `go.mod` не переименовываем.

## Альтернативы

- Всё в CLI - правила трудно проверить отдельно.
- DI-библиотека - лишняя зависимость для пяти компонентов.

## Последствия

- Плюсы: модель тестируется без консоли и файлов.
- Минусы: несколько небольших пакетов вместо одного.
