# 0002. Моки через mockery и testify

Дата: 2026-10-17

## Статус

`Принято`

## Контекст

Студентам нужно показать работу с моками на живом примере. В домене зоопарка
внешних зависимостей (сеть, БД) нет, поэтому моки нужны чисто в учебных целях.
Правила проекта запрещали внешние зависимости («внешних зависимостей нет
и не планируется») — это решение сознательно вводит первое исключение.

Ограничение инструмента: mockery v3 не умеет генерировать моки из интерфейсов,
объявленных в `_test.go`-файлах (vektra/mockery#700), поэтому интерфейс
обязан жить в обычном файле пакета.

## Решение

- В `internal/zoo/notifier.go` введён интерфейс `Notifier` (уведомления
  сотрудников о кормлении) и функция `FeedAll`, использующая его. Интерфейс
  объявлен на стороне потребителя — это отвечает правилу «интерфейсы ради
  подмены в тестах допустимы».
- Моки генерируются mockery v3 (`template: testify`) командой `make mocks`,
  конфиг — `.mockery.yml`. Сгенерированный файл `mock_<имя>_test.go` кладётся
  рядом с интерфейсом во внешний тестовый пакет (`zoo_test`), поэтому
  в продакшн-сборку не попадает.
- В `go.mod` добавлена зависимость `github.com/stretchr/testify`
  (нужна сгенерированному моку). Другие зависимости по-прежнему запрещены.
- Пример использования — `TestFeedAll` в `internal/zoo/zoo_test.go`.

## Альтернативы

- Ручные моки без библиотек — отклонены как основной пример: цель была
  показать именно mockery; ручной вариант остаётся запасным для офлайн-работы.
- Моки в отдельном пакете `internal/zoo/mocks` — отклонены: лишний пакет,
  а файл-`_test.go` во внешнем тестовом пакете не попадает в бинарь и не
  требует исключений в линтере.
- Интерфейс в `_test.go` — невозможно: mockery его не видит (см. контекст).

## Последствия

- Плюсы: студенты видят промышленный цикл «интерфейс → `make mocks` →
  типизированные ожидания `.EXPECT()`»; сгенерированный код не правится руками
  и перегенерируется одной командой.
- Минусы/риски: первая внешняя зависимость (testify + транзитивные) и новый
  инструмент в toolchain; студентам нужно ставить mockery
  (`go install github.com/vektra/mockery/v3@latest`).
