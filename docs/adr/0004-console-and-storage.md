# 0004. Пошаговое меню и хранение в памяти

Дата: 2026-10-26

## Статус

Принято

## Контекст

Спецификация задаёт команды 0–5 и последовательный ввод полей.
База данных и выдача в аренду не входят в задание.

## Решение

В `internal/cli` читать по одному полю на строку через `bufio.Scanner`.
Название может содержать пробелы. Расход спрашивать только у потребителей
энергии. При неверном поле отменять добавление и возвращаться к меню.
При конце ввода завершать работу без частичного добавления.
Ввод и вывод передавать через `io.Reader` и `io.Writer`.

В `domain.Park` хранить единый список инвентаря в порядке приёмки.
Инвентарные номера - положительные десятичные числа, общие для всего баланса.
Хранить номер строкой, удаляя ведущие нули: `001` и `1` - один номер.
Списки возвращать копиями. После выхода данные теряются.

## Альтернативы

- Команда со всеми полями в одной строке - расходится с пошаговым меню спецификации.
- База данных и интерфейс репозитория - лишние зависимости и код для текущей задачи.

## Последствия

- Плюсы: простой ввод, повторяемые тесты консоли, один источник данных для отчётов.
- Минусы/риски: линейный поиск номера; для небольшого учебного парка этого достаточно.
