# 0005. Консоль, память и экспорт

Дата: 2026-11-23

## Статус

Принято.

## Контекст

Нужны простой REPL (read eval print loop), аналитика и выгрузка без базы данных.

## Решение

Формат команд описан в спецификации; имя занимает остаток строки.
`app.Service` - фасад для консоли: загружает курс через порт `Repository`,
вызывает модель, сохраняет успешное изменение и строит сводку.
Репозиторий в памяти копирует агрегат при чтении и записи.
Экспорт вызывается через порт `Exporter`; адаптер пишет CSV в новый файл.
Ошибки домена - sentinel в `internal/domain/errors.go`, причины сохраняются через `%w`.
Моки портов генерирует mockery; ввод-вывод REPL подменяется в тестах.

## Альтернативы

- JSON-хранилище - сохранение между запусками не требуется.
- Файлы из домена - смешивают правила оценивания и ввод-вывод.

## Последствия

- Плюсы: один запуск без настройки; CSV открывается отдельно.
- Минусы: при выходе курс теряется; CSV нельзя импортировать обратно.
